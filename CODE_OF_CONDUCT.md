# Code de conduite

Nous voulons une communauté accueillante, respectueuse et inclusive.

Sont attendus : respect des personnes, critiques constructives, écoute des expériences différentes et langage professionnel. Le harcèlement, les attaques personnelles, la discrimination, les menaces et le partage de données privées sont inacceptables.

Signale un problème aux mainteneurs via les coordonnées indiquées dans `SECURITY.md` ou par un ticket privé approprié. Les mainteneurs peuvent modérer tout contenu ou comportement contraire à ces règles.
