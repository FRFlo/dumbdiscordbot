# Sécurité

Ne publie jamais de token Discord, clé API, contenu de `.env` ou donnée personnelle dans une issue ou une PR.

Pour signaler une vulnérabilité, ouvre un rapport privé aux mainteneurs via les [avis de sécurité GitHub](https://github.com/FRFlo/dumbdiscordbot/security/advisories/new). Indique la version concernée, l’impact, les étapes de reproduction et une proposition de mitigation si possible.

Les outils exécutant des actions Discord devront appliquer le principe du moindre privilège, valider leurs entrées et demander une confirmation avant les opérations irréversibles.
